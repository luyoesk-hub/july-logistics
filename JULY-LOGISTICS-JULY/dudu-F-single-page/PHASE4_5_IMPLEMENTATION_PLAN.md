## 🎯 **병렬 구현 전략**

### **트랙 A: Phase 4 (CSV 업로드) - 프론트엔드**

**담당:** HTML/JavaScript 수정  
**소요:** 8.5시간

#### **A-1: CSV 업로드 UI 구축** (2시간)
```
□ CSV 파일 선택 버튼 추가 (새 탭)
□ 드래그&드롭 영역 구현
□ 파일 정보 표시 (파일명, 크기, 행 수)
□ PapaParse 라이브러리 CDN 추가
```

#### **A-2: 필드 매핑 대화** (1.5시간)
```
□ CSV 헤더 자동 감지
□ 매핑 UI 구현 (헤더명 ↔ 필드명)
□ 선택적 필드 처리 (branch, shipping_option)
□ 매핑 저장/불러오기
```

#### **A-3: 데이터 검증** (2시간)
```
□ 행별 검증 함수 구현
  ├─ 필수값 확인
  ├─ 금지품목 검사
  ├─ 한도초과 검사
  └─ 규정 준수 확인
□ 검증 결과 색상 코딩 (성공/경고/오류)
□ 에러 메시지 표시
```

#### **A-4: 미리보기 & 일괄 접수** (2시간)
```
□ 미리보기 테이블 구현
□ 진행률 바 표시
□ 일괄 접수 실행
□ 완료 리포트 생성
□ 목록 자동 갱신
```

#### **A-5: 샘플 CSV 다운로드** (1시간)
```
□ 샘플 CSV 생성 버튼
□ 템플릿 CSV 제공
□ 사용자 가이드
```

---

### **트랙 B: Phase 5 (백엔드 & Supabase) - 서버**

**담당:** Express.js + Supabase  
**소요:** 26시간

#### **B-1: Supabase 초기 설정** (2시간)
```
□ Supabase 프로젝트 생성
□ PostgreSQL 데이터베이스 초기화
□ API 키 발급
□ 프로젝트 설정 저장
```

#### **B-2: 데이터베이스 스키마** (3시간)
```
□ users 테이블 생성
□ shipments 테이블 생성
□ branches 테이블 생성
□ RLS (Row Level Security) 정책 설정
□ 인덱스 최적화
```

#### **B-3: Express 서버 기본 설정** (2시간)
```
□ Express.js 프로젝트 초기화
□ 기본 라우팅 설정
□ CORS 설정 (프론트엔드 도메인)
□ 요청/응답 미들웨어
□ 에러 핸들러
```

#### **B-4: 인증 구현** (2시간)
```
□ JWT 토큰 생성/검증
□ 로그인 엔드포인트
□ 사용자 등록 엔드포인트
□ 토큰 리프레시
□ 미들웨어 (인증 확인)
```

#### **B-5: CRUD API 구현** (4시간)
```
□ POST /api/shipments (신규 접수)
□ GET /api/shipments (목록 조회)
□ GET /api/shipments/:id (상세 조회)
□ PATCH /api/shipments/:id (수정)
□ DELETE /api/shipments/:id (삭제)
□ 페이지네이션
```

#### **B-6: 통계 API** (3시간)
```
□ GET /api/statistics (KPI)
□ GET /api/statistics/by-branch (지점별)
□ GET /api/statistics/by-region (권역별)
□ GET /api/statistics/by-grade (등급별)
□ GET /api/statistics/by-shipping-option (배송옵션별)
```

#### **B-7: 검색 & 필터** (2시간)
```
□ 운송장 번호 검색
□ 이름 검색
□ 날짜 범위 필터
□ 상태 필터
□ 지점 필터
```

#### **B-8: 권한 관리** (3시간)
```
□ 사용자 역할 정의 (reception/manager/admin)
□ 역할별 권한 검증
□ 지점별 데이터 접근 제어
□ RLS 정책 적용
```

#### **B-9: 배포 준비** (3시간)
```
□ 환경 변수 설정
□ 데이터베이스 마이그레이션
□ API 문서화 (Swagger)
□ 성능 테스트
□ 보안 검사
```

#### **B-10: 배포** (2시간)
```
□ Railway/Heroku 선택
□ 배포 설정
□ 도메인 연결
□ 모니터링 설정
□ 에러 로깅
```

2. 검증된 데이터 → Supabase DB 저장
3. 응답 → 프론트엔드 목록 업데이트
4. 통계 → 실시간 계산 (DB)
