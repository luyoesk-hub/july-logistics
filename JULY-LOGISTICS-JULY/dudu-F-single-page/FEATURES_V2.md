# 두두택배 접수 시스템 - Phase 2 신규 기능

> 배포일: 2026-08-07  
> 추가 기능: 주소록(Address Book) + 배송 옵션(Shipping Options)

---

## 🎯 신규 기능 개요

### 1. 주소록 (Address Book)

**목적:** 반복적인 배송 입력을 빠르게 처리

**사용 방법:**
1. "보내는 분 이름"과 "도착 지역"을 입력합니다
2. "저장" 버튼을 클릭하면 최근 5개 주소가 저장됩니다
3. 다시 같은 배송을 하려면 드롭다운에서 선택하고 "적용" 클릭
4. 자동으로 입력값이 채워집니다

**기술 사항:**
- 브라우저 localStorage에 저장 (세션 유지)
- 같은 주소는 자동으로 최근순으로 정렬
- 최대 5개까지만 보관

**예시:**
```
저장된 주소:
1. 김민준 → 서울
2. 이서연 → 부산
3. 박준호 → 인천
(최대 5개)
```

---

### 2. 배송 옵션 (Shipping Options)

**목적:** 배송 속도와 비용 선택권 제공

#### 세 가지 옵션

| 옵션 | 요금 | 도착예정일 | 사용 사례 |
|------|------|----------|---------|
| **스탠다드** (기본) | 정가 | 규정 도착일 | 일반 배송 |
| **익스프레스** | 정가 × 1.2 (+20%) | 1일 더 빠름 | 급할 때 |
| **나이트** | 정가 × 1.5 (+50%) | 다음날 도착 | 매우 급할 때 |

#### 요금 계산 예시

**기본 사례: 중형 패키지, 일반 지역, 기본 요금 6,000원**

```
스탠다드   → 6,000원   (다음 영업일 도착)
익스프레스 → 7,200원   (1일 빠름)
나이트     → 9,000원   (다음날 도착)
```

## 📋 사용 시나리오

### 시나리오 1: 반복 배송 (주소록 활용)

```
1. 처음 배송
   - 지점: 서울지점
   - 보내는 분: 김민준
   - 받는 분: 이서연
   - 도착지역: 서울
   → "저장" 버튼 클릭

2. 두 번째 배송 (같은 보낸이, 같은 지역)
   - 드롭다운에서 "김민준 → 서울" 선택
   - 입력값 자동 채우기
   - 받는 분만 변경 (이순신)
   → 30초 안에 완료
```

### 시나리오 2: 급배송 (배송 옵션 활용)

```
1. 일반 배송
   - 기본 요금: 6,000원
   - 도착: 2026-08-08 (다음 영업일)

2. 익스프레스 필요
   - 요금: 6,000 × 1.2 = 7,200원
   - 도착: 2026-08-07 (오늘!)

3. 나이트 배송 필요
   - 요금: 6,000 × 1.5 = 9,000원
   - 도착: 2026-08-07 (오늘 중)
```

## 🔍 계산 과정 (화면 우측)

### 배송 옵션이 추가된 계산 단계

```
1단계: 부피 무게 계산
  가로 60 × 세로 40 × 높이 50 / 6000 = 20kg

2단계: 요금 무게
  실제 무게 3kg vs 부피 무게 20kg → 20kg

3단계: 세 변의 합
  60 + 40 + 50 = 150cm

4단계: 크기 등급 판정
  150cm / 20kg → 대형

5단계: 권역 판정
  서울 → 일반 지역

6단계: 요금 조회
  대형 × 일반 = 9,000원 (기본 요금)

7단계: 배송 옵션 요금
  익스프레스 선택 시: 9,000원 × 1.2 = 10,800원

8단계: 도착 예정일
  스탠다드: 2026-08-08(목)
  익스프레스: 2026-08-07(수)
  나이트: 2026-08-07(수) 중
```

## 📊 목록 및 통계 업데이트

### 목록 탭 (목록 및 조회)

**새 컬럼 추가:**
- 배송옵션: 스탠다드 / 익스프레스 / 나이트
- 요금: 최종 요금 (배송 옵션 적용됨)

**예시 테이블:**
```
운송장    | 지점   | 보낸이  | 받는이  | 배송옵션  | 요금    | 도착예정
---------|--------|--------|--------|----------|---------|----------
1100001  | 서울   | 김민준 | 이서연 | 익스프레스 | 7,200원 | 2026-08-07
1100002  | 서울   | 박준호 | 최지운 | 스탠다드  | 6,000원 | 2026-08-08
```

### 통계 탭 (통계 대시보드)

**통계 기반 변경:**
- 총 요금: 최종 요금(배송 옵션 적용) 기반
- 평균 요금: 배송 옵션이 반영됨
- 지점별/권역별/등급별 통계 모두 최종 요금 기반

**예시:**
```
배송옵션 비율 분석 (앞으로 추가 예정)
- 스탠다드: 60%
- 익스프레스: 30%
- 나이트: 10%
```

## 🔧 기술 상세 사항

### 요금 계산 공식

```javascript
// 기본 요금 (규정 §3 요금표)
basePrice = RATE_TABLE[grade][region]

// 배송 옵션 배수
multiplier = {
  'standard': 1.0,
  'express': 1.2,
  'overnight': 1.5
}

// 최종 요금 (올림)
finalPrice = Math.round(basePrice * multiplier)
```

### 도착 예정일 계산

```javascript
// 영업일 계산 (주말 제외)
baseBusinessDays = ETA_BUSINESS_DAYS[region]  // 1~3일

// 배송 옵션 오프셋
dayOffset = {
  'standard': 0,
  'express': -1,    // 1일 빠름
  'overnight': -2   // 2일 빠름
}

// 최종 영업일
totalBusinessDays = baseBusinessDays + dayOffset
```

### localStorage 구조

```javascript
// 주소록
{
  addressBook: [
    { senderName: '김민준', receiverArea: '서울' },
    { senderName: '이서연', receiverArea: '부산' },
    ...
  ]
}

// shipment 레코드 추가 필드
{
  basePrice: 6000,           // 규정 기본 요금
  shippingOption: 'express', // 배송 옵션
  finalPrice: 7200           // 최종 요금
}
```
