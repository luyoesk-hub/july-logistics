## 시스템 개요

### 시스템 목적
> 두두택배의 일일 접수 업무를 **한 화면에서 완성**  
> 규정 100% 준수하며 **실시간 계산** 과정 표시

### 주요 사용자
- **접수 담당자** (주 사용자)
- **운영 관리자** (통계 확인용)
- **배송 기사** (향후: 상태 업데이트)

### 핵심 가치
```
입력 즉시 계산 → 규정 준수 자동화 → 운영 효율 50% 증대
```

### 📑 TAB 1: 접수 (Reception)

#### 1-1. 레이아웃 구조

```
┌─────────────────────────────────────────────────────────────────┐
│ 접수 정보 입력 (좌측)              │ 계산 과정 (우측)            │
│                                   │                            │
│  • 접수 지점                      │  ▶ 부피 무게 계산           │
│  • 보내는 분 + 주소록             │  ▶ 요금 무게               │
│  • 받는 분                        │  ▶ 세 변의 합              │
│  • 도착 지역                      │  ▶ 크기 등급 판정          │
│  • 배송 옵션                      │  ▶ 권역 판정               │
│  • 물품명                         │  ▶ 요금 조회               │
│  • 무게 + 크기                    │  ▶ 배송옵션 요금           │
│                                   │  ▶ 도착 예정일             │
│  [새로 입력] [접수 완료]          │                            │
│                                   │  요금표 (4등급×3권역)      │
└─────────────────────────────────────────────────────────────────┘

⬇ 접수 완료 시

┌─────────────────────────────────────────────────────────────────┐
│ 📋 접수가 완료됐습니다                                            │
│                                                                 │
│ 운송장번호: 1100000001                                           │
│ 접수 지점: 서울지점 / 보내는 분: 김민준                         │
│ 받는 분: 이서연 / 도착 지역: 서울(일반)                        │
│ 물품: 이불 / 요금 무게: 20kg / 등급: 대형                     │
│ 배송옵션: 익스프레스                                             │
│ 요금: 9,000원(기본) + 익스프레스(+20%) = 10,800원             │
│ 도착 예정일: 2026-08-07(수)                                    │
└─────────────────────────────────────────────────────────────────┘
```

#### 1-2. 입력 필드 상세

| 필드 | 타입 | 필수 | 기본값 | 유효성 | 비고 |
|------|------|------|--------|--------|------|
| 접수 지점 | 텍스트 | Y | - | 6개 등록 지점 | 목록 없는 입력 시 00 코드 |
| 보내는 분 | 텍스트 | Y | - | 비어있음 제외 | **주소록 연동** |
| 받는 분 | 텍스트 | Y | - | 비어있음 제외 | - |
| 도착 지역 | 텍스트 | Y | - | 권역 자동 판정 | 제주/도서산간/일반 |
| 배송 옵션 | 라디오 | Y | 스탠다드 | 3개 선택지 | **Phase 2 추가** |
| 물품명 | 텍스트 | Y | - | 금지품목 검사 | 21개 키워드 |
| 실제 무게 | 숫자 | Y | - | > 0 | kg 단위 |
| 가로/세로/높이 | 숫자 | Y | - | > 0 | cm 단위 |

#### 1-6. 우측 계산 패널 (실시간 갱신)

```
계산 과정 (규정 §1-9를 그대로 옮겼습니다)

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

① 부피 무게 계산 (규정 §4)
   가로 60 × 세로 40 × 높이 50 / 6000 = 20kg

② 요금 무게 (규정 §4)
   실제 무게 3kg 과 부피 무게 20kg 중 큰 값 = 20kg

③ 세 변의 합 (규정 §3)
   60 + 40 + 50 = 150cm

④ 크기 등급 판정 (규정 §3, §8-4)
   극소형(60cm/2kg 이하): 세변합 기준 초과
   소형(80cm/5kg 이하): 세변합 기준 초과
   중형(120cm/15kg 이하): 세변합 기준 초과
   대형(160cm/25kg 이하): 통과 -> 이 등급 채택

⑤ 권역 판정 (규정 §2, §8-6)
   도착 지역 "서울" -> 일반

⑥ 요금 조회 (규정 §3 요금표)
   대형 등급 x 일반 권역 = 9,000원

⑦ 배송 옵션 요금 (Phase 2 추가)
   익스프레스 선택 시: 9,000원 × 1.2 = 10,800원

⑧ 도착 예정일 (규정 §6 - 일반 권역 1영업일)
   2026-08-06(화) - 접수일
   2026-08-07(수) - 영업일 1일째 -> 도착 예정
   
   (익스프레스 선택 시: 1일 빠름 -> 2026-08-06)

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

요금표 - 4등급 × 3권역 12종 (규정 §3)

║ 등급  ║ 기준(세변합/무게)    ║ 일반  ║ 제주  ║ 도서산간 ║
╠═══════╬════════════════════╬════════╬════════╬══════════╣
║ 극소형║ 60cm 이하 / 2kg    ║ 3,500원║ 6,500원║ 8,500원  ║
║ 소형  ║ 80cm 이하 / 5kg    ║ 4,000원║ 7,000원║ 9,000원  ║
║ 중형  ║ 120cm 이하 / 15kg  ║ 6,000원║ 9,000원║11,000원  ║
║ 대형  ║ 160cm 이하 / 25kg  ║ 9,000원║12,000원║14,000원  ║
╚═══════╩════════════════════╩════════╩════════╩══════════╝
    ↑ 선택된 등급/권역 강조
```

### 핵심 알고리즘

```javascript
volumeWeightKg = (width × height × depth) / 6000
```

#### 요금 무게 (규정 §4)
```javascript
billedWeightKg = max(actualWeight, volumeWeight)
```

#### 크기 등급 판정 (규정 §3, §8-4)
```javascript
// 순서대로 검사, 처음 맞는 등급 채택
for (tier of RATE_TABLE) {
  if (sumCm <= tier.maxSum && billedWeight <= tier.maxWeight)
    return tier.grade
}
return null  // 접수 불가
```

#### 배송 옵션 요금 (Phase 2)
```javascript
multiplier = {
  'standard': 1.0,
  'express': 1.2,
  'overnight': 1.5
}
finalPrice = round(basePrice × multiplier)
```

#### 도착 예정일 (규정 §6 + Phase 2)
```javascript
baseBusinessDays = ETA_BUSINESS_DAYS[region]  // 1~3
dayOffset = {
  'standard': 0,
  'express': -1,
  'overnight': -2
}
totalBusinessDays = baseBusinessDays + dayOffset
// 주말 제외하고 영업일 카운트
```
