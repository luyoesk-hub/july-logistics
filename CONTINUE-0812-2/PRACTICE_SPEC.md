# 실습 요구사항
## 한 줄 목표
사용자가 입력한 피드백을 유형별 해결방법과 이유 그리고 다음행동으로 바꾼다
.
## 입력
- 입력 이름: [예: 고객 피드백/
- 입력 형식: [예: 한 문장/
- 빈 입력 처리: 고객 피드백]: 한 문장]: "입력해주세요"라고 출력하고종료한다.
## 출력 계약
1. [항목 1]: [허용값 또는 형식]
2. [항목 2]: [허용값 또는 형식]
3. [항목 3]: [허용값 또는 형식]
4. [항목 4]: [허용값 또는 형식]
## 기술 계약
- 수정 파일: app.py
- API 키: .env의 GOOGLE
- 모델: gemini-3.5-flash-lite
- 정상 입력당 API 호출: 1회
- 실패 시 실제 오류를 출력한다.
- API 키는 출력하지 않는다.
KEY

- 테스트 C: 빈 입력
