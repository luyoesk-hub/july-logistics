# 구현 계획 (PLAN.md)

1. 환경과 의존성 확인
   - `.env` 파일 내 API 키 존재 여부 확인 (값 자체는 비공개 유지)
   - 파이썬 환경 및 Gemini API 연동을 위한 패키지 확인

2. app.py 구현
   - `PRACTICE_SPEC.md` 요구사항 반영 (`app.py`만 수정)
   - 빈 입력 처리 ("입력해주세요" 출력 후 종료)
   - Gemini API (`gemini-2.5-flash-lite`) 호출 및 예외 처리 (실제 오류 출력, API 키 미출력)

3. 로컬 테스트 A, B, C 실행
   - 테스트 A (정상 입력 1) 실행
   - 테스트 B (정상 입력 2) 실행
   - 테스트 C (빈 입력) 실행
